# 검색대 적발 시 절차

공항·항만 검색대에서 신청받지 않은 동산이 일반동산문화유산으로 적발된 경우, 감정위원이 현장에서 수행할 절차를 단계별로 안내하는 모바일 우선 체크리스트 도구.

## 접속

GitHub Pages 활성화 후 다음 URL로 접근:

```
https://{사용자명}.github.io/{저장소명}/
```

모바일 브라우저에서 위 URL을 열고 **홈 화면에 추가**하면 앱처럼 작동합니다 (iOS Safari "공유 → 홈 화면에 추가" / Android Chrome "메뉴 → 앱 설치").

## 전체 흐름

```
시작 (판단 기준 · 시행령 별표 3 + 특사경 자격 선택)
  └─ 현장 도착 · 사전 확인 의무 안내 · 신청서 작성 · 감정
        ├─ 비문화유산 판별 → 출국 허용 (종결)
        ├─ 일반동산문화유산 판별 → 위반 고지 + 임의제출 거부권 고지
        │     ├─ 임의제출 동의 → 임의제출서·압수목록 교부·인수 → 출국 → 감정관실 사후 처리
        │     ├─ 임의제출 거부 + 신원 협조 → 형소법 제216조 ③ 압수 → 출국 → 사후 처리 (+ 사후 영장 청구)
        │     └─ 전면 거부 → 공항경찰대 또는 사범단속팀 인계 → 사후 처리
        └─ 신청서 작성 거부 → 다국어 재시도 → 위원 직권 감정
              ├─ 비문화유산 판단 → 출국 허용
              └─ 일반동산 판단 → 위반 고지 → 후속 분기 (동의 / 거부+협조 / 전면거부)
```

## 절차 설계의 골격

법 제60조 ⑤항의 사전 확인 의무는 **사전 행정의무**입니다 (시행령 제37조 ①항: 감정위원의 감정으로 확인). 검색대 미신청 적발은 이 의무를 사후 보완하는 절차로 설계되어 있고, 감정 결과가 확정되기 전까지 화주는 피의자가 아닌 행정처분의 상대방으로 다루어집니다. 일반동산문화유산으로 판별된 시점에 비로소 법 제60조 ①항(제39조 ①항 준용) 무허가 반출 금지 위반이 성립하고 법 제90조 ②항에 따른 처벌·몰수 대상이 됩니다.

화주가 신청서 작성을 거부하더라도 위원은 **직권으로 외관 감정**을 실시하여 현장에서 판단을 종결합니다. 신청서 작성은 화주의 행정의무이지 위원의 감정 권한 발동 요건이 아닙니다.

특사경 자격 보유 위원은 임의제출 단계 진입 시 지명서 제시 및 신분 고지가 필수이며(직무규정 제12조 ②), 비특사경 위원은 압수 권한이 없으므로 사범단속팀 출동 또는 공항경찰대 협조를 받습니다.

- 「문화유산의 보존 및 활용에 관한 법률 시행규칙」 제48조 · 별지 제78호
- 「문화유산감정관실 설치·운영 규정」 (국가유산청훈령 제2호)

- 「형사소송법」 제129조(압수목록 교부) · 제211조 · 제212조 · 제216조 · 제218조 · 제219조

## 기술 사양

- 단일 HTML 파일, 외부 의존성 없음 (Google Fonts만 CDN 로딩)
- localStorage 기반 진행 상태 저장 · 페이지 종료 후에도 복구 가능
- 모바일 우선 반응형, 최초 로딩 후 오프라인 작동
- PWA 호환 · 홈 화면 추가 시 전체 화면 앱처럼 작동
- 필수 항목 미체크 시 진행 차단 + 시각 강조 안내

## 면책

본 도구는 감정위원이 개인적으로 제작한 현장 보조 도구이며, 국가유산청의 공식 매뉴얼이 아닙니다. 법령 적용 및 실무 처리 시 시행 규정과 담당과장 지시에 따르십시오. 법령 개정 시점에 따른 내용 정합성은 사용자가 확인해야 합니다.
