# 검색대 적발 감정 절차 가이드

공항·항만 검색대에서 신청받지 않은 동산이 일반동산문화유산으로 적발된 경우, 감정위원이 현장에서 수행할 절차를 단계별로 안내하는 모바일 우선 체크리스트 도구.

## 접속

GitHub Pages 활성화 후 다음 URL로 접근:

```
https://{사용자명}.github.io/{저장소명}/
```

모바일 브라우저에서 위 URL을 열고 **홈 화면에 추가**하면 앱처럼 작동합니다 (iOS Safari "공유 → 홈 화면에 추가" / Android Chrome "메뉴 → 앱 설치").

## 주요 흐름

```
시작 (일반동산문화유산 판단 기준 · 시행령 별표 3)
  └─ 특사경 자격 여부 선택
        └─ 현장 도착 · 위반 고지 (감정위원 신분)
              ├─ 협조 → 임의제출 절차 (특사경 본인은 지명서 제시)
              │       ├─ 내국인 출국
              │       └─ 외국인 출국
              │           └─ 감정관실 사후 처리 (사진·경위서·정책과 보고·인계)
              └─ 비협조 → 공항경찰대 또는 사범단속팀 협조
                        └─ 감정관실 사후 처리
```

## 법령 근거

- 「문화유산의 보존 및 활용에 관한 법률」 제39조·제60조·제90조
- 「문화유산의 보존 및 활용에 관한 법률 시행령」 제36조·별표 3 (2024. 7. 23. 개정)
- 「문화유산감정관실 설치·운영 규정」 (국가유산청훈령 제2호)
- 「국가유산청 특별사법경찰관리 직무규정」 (국가유산청훈령 제2호)
- 「형사소송법」 제211조·제212조

## 기술 사양

- 단일 HTML 파일, 외부 의존성 없음 (Google Fonts만 CDN 로딩)
- localStorage 기반 진행 상태 저장 — 화면 종료 시에도 복구 가능
- 모바일 우선 반응형, 오프라인 작동 (최초 로딩 후)
- PWA 호환 — 홈 화면 추가 시 전체 화면 앱처럼 작동

## 면책

본 도구는 감정위원이 개인적으로 제작한 현장 보조 도구이며, 국가유산청의 공식 매뉴얼이 아닙니다. 법령 적용 및 실무 처리 시 시행 규정과 담당과장 지시에 따르십시오.
